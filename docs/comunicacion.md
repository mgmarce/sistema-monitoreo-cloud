# Comunicación del Equipo

## Proyecto

Sistema de Monitoreo de Recursos Cloud con Grafana

## Fase

Fase 0 – Onboarding y planificación

## Canal principal de comunicación

**Grupo de WhatsApp**

El grupo de WhatsApp será utilizado como canal principal para la comunicación rápida y coordinación entre los integrantes del equipo.

## Uso del canal

El canal será utilizado para:

- Coordinar actividades.
- Comunicar avances.
- Informar bloqueos o dificultades.
- Coordinar reuniones.
- Compartir avisos relacionados con el proyecto.
- Dar seguimiento a las tareas pendientes.

## Integrantes

- Marcela – Líder de proyecto
- Adonay – Ingeniero Cloud
- Rolando – DevOps
- Luis – Analista de métricas
- Edy – Documentador Técnico

## Reuniones

Cuando sea necesario realizar reuniones de trabajo, se utilizará Google Meet para:

- Revisar avances.
- Analizar problemas.
- Tomar decisiones técnicas.
- Coordinar actividades.
- Revisar los entregables.

## Normas de comunicación

1. Utilizar WhatsApp como canal principal para la comunicación rápida.
2. Comunicar oportunamente los avances de las actividades.
3. Informar los bloqueos que puedan afectar una tarea.
4. Registrar los acuerdos técnicos importantes en la documentación.
5. Evitar compartir contraseñas, tokens, claves privadas o información sensible en el grupo.
6. Mantener las conversaciones relacionadas con las actividades del proyecto.
7. Mantener una comunicación respetuosa entre los integrantes.
