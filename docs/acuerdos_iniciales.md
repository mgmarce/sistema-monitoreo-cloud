## Acuerdos establecidos

### 1. Organización del equipo

Se establecieron los roles iniciales de los integrantes y las responsabilidades generales asociadas a cada función.

### 2. Canal de comunicación

Se utilizará un grupo de WhatsApp como canal principal para la comunicación rápida y coordinación del equipo.

### 3. Repositorio

Se utilizará GitHub como repositorio del proyecto para almacenar documentación, código, configuraciones y evidencias correspondientes.

**Repositorio:** [[Repositorio github](https://github.com/mgmarce/sistema-monitoreo-cloud)]

### 4. Herramientas de monitoreo

Se identificaron como herramientas principales:

- Prometheus
- Node Exporter
- Grafana
- Alertmanager

Estas herramientas corresponden a la propuesta inicial del proyecto. La implementación y configuración se realizará posteriormente.

### 5. Recursos cloud

Se propusieron inicialmente recursos asociados a:

- API
- Base de datos
- Web
- Documentación
- Respaldo

La infraestructura definitiva, proveedores y costos quedan pendientes de validación.

### 6. Métricas

Se identificaron inicialmente las siguientes métricas:

- CPU
- RAM
- Disco
- Uptime
- Latencia
- HTTP Status

La prioridad y los umbrales definitivos serán definidos durante la fase de análisis.

### 7. Documentación

Se acordó mantener organizada la documentación del proyecto dentro del repositorio.

La documentación incluirá:

- Roles.
- Comunicación.
- Recursos tecnológicos.
- Acuerdos.
- Backlog.
- Bitácoras.
- Evidencias.

### 8. Evidencias

Cada integrante deberá registrar sus actividades y conservar evidencias verificables de sus aportes.

### 9. Seguimiento

Se realizará una revisión periódica del avance del proyecto y cada integrante deberá mantener actualizada su bitácora.
