# Roles y Responsabilidades del Equipo

## Proyecto

Sistema de Monitoreo de Recursos Cloud con Grafana

## Fase

Fase 0 – Onboarding y planificación

## Equipo

Equipo de Monitoreo Cloud

## Integrantes

| Integrante | Rol | Responsabilidades |
|---|---|---|
| Marcela | Líder de proyecto | Coordinar al equipo, distribuir actividades, dar seguimiento y consolidar avances. |
| Adonay | Ingeniero Cloud | Analizar la infraestructura cloud, recursos, instancias, red y accesos necesarios para el proyecto. |
| Rolando | DevOps | Definir el stack de monitoreo y posteriormente apoyar su configuración e integración. |
| Luis | Analista de métricas | Definir las métricas a monitorear, prioridades y criterios relacionados con el monitoreo. |
| Edy | Documentador Técnico | Organizar la documentación técnica, acuerdos, evidencias y trazabilidad de las actividades. |

## Responsabilidades iniciales

### Marcela – Líder de proyecto

- Coordinar las actividades del equipo.
- Distribuir tareas.
- Dar seguimiento al avance.
- Coordinar reuniones.
- Consolidar los avances del equipo.
- Mantener comunicación con los integrantes.

### Adonay – Ingeniero Cloud

- Analizar los recursos cloud que serán considerados para el monitoreo.
- Identificar las instancias necesarias.
- Revisar las necesidades de infraestructura.
- Analizar aspectos relacionados con accesos y conectividad.
- Apoyar la elaboración del Plan de Recursos Tecnológicos.

### Rolando – DevOps

- Analizar las herramientas necesarias para el sistema de monitoreo.
- Definir el stack tecnológico inicial.
- Preparar posteriormente las configuraciones de monitoreo.
- Apoyar la integración de los componentes.

### Luis – Analista de métricas

- Identificar las métricas que deberán monitorearse.
- Clasificar las métricas según su prioridad.
- Definir posteriormente umbrales y criterios de criticidad.
- Apoyar el diseño de los dashboards desde la perspectiva de las métricas.

### Edy – Documentador Técnico

- Organizar la documentación técnica.
- Registrar acuerdos y decisiones.
- Organizar las evidencias del proyecto.
- Mantener la estructura documental.
- Apoyar la trazabilidad de actividades y entregables.
- Consolidar la documentación generada por los integrantes.

## Acuerdos de trabajo

- Cada integrante será responsable de las actividades relacionadas con su rol.
- Los avances y bloqueos deberán comunicarse mediante el canal establecido.
- Los acuerdos técnicos importantes deberán quedar registrados.
- Cada integrante deberá conservar evidencia de sus aportes.
- La documentación será actualizada conforme avance el proyecto.

## Estado

Roles iniciales definidos durante la Fase 0.
